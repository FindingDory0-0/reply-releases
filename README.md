# Reply 배포

메일·메신저 답장을 AI가 써 주는 맥 앱 **Reply** 의 설치 파일과 자동 업데이트 파일을 올리는 곳입니다. 소스는 비공개 저장소에 있습니다.

## 설치

1. [최신 릴리스](https://github.com/FindingDory0-0/reply-releases/releases/latest)에서 `Reply-<버전>-arm64.dmg` 를 받습니다 (Apple 실리콘 맥).
2. dmg 를 열고 Reply 를 응용 프로그램 폴더로 끌어 놓습니다.
3. 처음 열 때 "확인되지 않은 개발자" 경고가 나오면 **시스템 설정 › 개인정보 보호 및 보안 › 그래도 열기** 를 한 번 누릅니다.

이후 새 버전은 앱이 알아서 받아 설치합니다.
